# 📊 Sales Dashboard – Microsoft Excel

An interactive **Sales Dashboard built using Microsoft Excel** to analyze sales performance, profitability, customer trends, and category-wise sales.

## 📈 Dashboard Overview

The dashboard provides a consolidated view of sales and profit performance through interactive visualizations and filters.

### 🔹 Key Analysis

- 💰 **Profit Gained** – Tracks yearly profit performance across different product categories.
- 🗺️ **Sales by State** – Visualizes geographical sales performance across different states.
- 🛍️ **Sales by Category** – Compares sales across different product categories and sub-categories.
- 📅 **Monthly Sales** – Shows monthly sales trends and identifies high and low-performing months.
- 👥 **Customer Count** – Displays the number of customers across different years.
- 🏆 **Top 5 Customers Making Profit** – Highlights the top customers based on profit contribution.
- 🎛️ **Interactive Filters** – Allows users to filter the dashboard by Year and Category.

## 🛠️ Tools & Techniques

- Microsoft Excel
- Pivot Tables
- Pivot Charts
- Slicers
- Excel Maps
- Data Analysis
- Data Visualization
- KPI & Performance Analysis

## 🎯 Objective

The objective of this project is to transform raw sales data into an **interactive business intelligence dashboard** that makes it easier to understand sales trends, identify profitable customers and categories, compare regional performance, and support data-driven decision making.

## 💡 Key Insights

The dashboard helps answer questions such as:

- Which category generates the highest sales?
- Which states contribute the most to sales?
- How do sales change month-to-month?
- How has profit changed over the years?
- Who are the top 5 customers contributing to profit?
- How does customer count change each year?
- Which product categories are performing better?
